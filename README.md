# Market on Wheels - Web App

Market on Wheels is an intelligent multi-vendor hyperlocal marketplace platform that allows customers to discover nearby stores, add products from multiple vendors into a single cart, and receive them in one unified delivery.

## 🌐 Features

- **Multi-Vendor Unified Cart**: Seamlessly purchase items from multiple local vendors in one checkout.
- **Smart Delivery Zone & Fee Simulator**: Dynamic calculation based on distance and order logistics.
- **Hyperlocal Vendor Discovery**: Discover nearby shops, fresh produce, bakeries, and essentials.
- **AI Shopping Assistant**: Autonomous ordering simulation with customer confirmation and smart recommendations.
- **Visual Order Timeline**: Multi-vendor pickup tracking and live status updates.
- **Customer Hub**: Profile, order history, wishlist, and notification center.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS, PostCSS, Autoprefixer
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Forms**: React Hook Form

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Mubashirijaz786/Market-on-wheels-Web-App.git
   cd Market-on-wheels-Web-App
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build:
   ```bash
   npm run preview
   ```
